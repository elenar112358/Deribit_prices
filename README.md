Celery Beat — планировщик
Следит за расписанием и раз в минуту отправляет задачу на выполнение.




Redis — брокер сообщений
Принимает сообщения от Beat и передаёт их рабочему процессу. Это отдельный сервис, не замена PostgreSQL.




Celery Worker — исполнитель
Получает задачу из Redis и запускает Python-функцию.




PostgreSQL — хранилище
Хранит историю цен, которую затем читают API твоего приложения.
